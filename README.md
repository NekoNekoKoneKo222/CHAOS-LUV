# CHAOS-LUV

友達と発明する、PC・iPad対応の3Dオンライン物理サンドボックスゲーム。

## 実装済み（第1〜3段階の試作版）

- **第1段階**: 3Dワールド、移動/ジャンプ/カメラ、ルームコード式4〜8人参加、サーバー権威型物理演算、箱/球/円柱の設置・移動・削除・固定、ワールドの手動保存/読み込み
- **第2段階**: 固定・ヒンジ・モーター・ピストンの物理ジョイント、ロープ/バネ風接続、線を描いて剛体セグメント化、複数選択/グループ移動、設計図を端末内に保存し再配置
- **第3段階**: センサー・スイッチと信号線の簡易回路、モーター/ピストン制御、NPCの自由歩行/追従/作業地点への移動/座席利用

※ まだ試作段階です。複雑な機械の安定性、NPC経路探索、剛体の表面に沿った自由線描画、完全な柔軟物理、永久保存DBは未完成です。ロープ/バネは距離拘束の簡易シミュレーションです。

## セットアップ

Node.js 20以上を推奨。

~~~bash
npm install
npm run dev
~~~

Vite側の http://localhost:5173 を開いてください。ViteがWebSocketを localhost:3000 にプロキシします。

本番:

~~~bash
npm install
npm run build
npm start
~~~

PORT 環境変数を利用し、0.0.0.0 にバインドします。GET /healthz がヘルスチェックです。

## セーブの重要な注意点

- ワールドデータは **ホスト端末のlocalStorage** に手動保存、60秒おきに自動バックアップします（バックアップは接続中のホスト宛て）。
- ワールドをJSONでダウンロードし、インポートできます。
- ルーム自体はサーバーのメモリに存在し、Renderの再起動時に消えます。部屋の内容を永久保存するには今後データベース接続を追加します。
- 設計図は作成したブラウザ内に保存されます。

## マルチプレイの仕組み

Node.js + WebSocketサーバーが Rapier 3Dの物理世界を管理します。クライアントはThree.jsで描画し、操作リクエストをサーバーに送信します。操作権限（パーツ所有者/ルームホスト）、数値やサイズ、数量上限の検査をサーバーが行います。

一つのサーバーインスタンスでルームを処理します。複数インスタンス間のルーム共有は未対応です。Renderの無料プランはCPUリソースが限られるため、同時のルームや大量の物理演算は重くなる場合があります。
